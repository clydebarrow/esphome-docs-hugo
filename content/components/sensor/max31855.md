The `max31855` temperature sensor allows you to use your MAX31855 thermocouple
temperature sensor ([datasheet](https://datasheets.maximintegrated.com/en/ds/MAX31855.pdf)) with ESPHome

As the communication with the MAX31855 is done using SPI, you need
to have an [SPI bus]({{< ref "components/spi#spi" >}}) in your configuration with the **miso_pin** set (MOSI is not required).

Connect `GND` to `GND`, `VCC` to `3.3V` and the other three `MISO` (or `SO` for short),
`CS` and `CLOCK` (or `CLK`) to free GPIO pins.

![.. code:: yaml](../images/temperature.png)
*.. code:: yaml*


    # Example configuration entry
    spi:
      miso_pin: D0
      clk_pin: D1

    sensor:
      - platform: max31855
        name: "Living Room Temperature"
        cs_pin: D2
        update_interval: 60s

## Configuration variables:

- **cs_pin** (**Required**, [Pin Schema]({{< ref "guides/configuration-types#config-pin_schema" >}})): The Chip Select pin of the SPI interface.
- **update_interval** (*Optional*, [config-time]({{< ref "guides/configuration-types#config-time" >}})): The interval to check the sensor. Defaults to `60s`.
- **reference_temperature** (*Optional*, [config-id]({{< ref "guides/configuration-types#config-id" >}})): Access the internal temperature sensor of the MAX31855.

  - All options from [Sensor]({{< ref "components/sensor/_index#config-sensor" >}}).

- **spi_id** (*Optional*, [SPI Component]({{< ref "components/spi#spi" >}})): Manually specify the ID of the [config-id]({{< ref "guides/configuration-types#config-id" >}}) if you want to use multiple SPI buses.
- All other options from [Sensor]({{< ref "components/sensor/_index#config-sensor" >}}).
